# Workshop manuscript figures

These vector figures use one publication layout and fixed semantic color system across the v0.21 draft. Figures 2-6 use the four current physician datasets; Bolun's breast and PDAC ratings are stored in separate source workbooks. Patient-letter findings remain a qualitative Discussion topic, so no letter plot is embedded. The final test-set LLM audit is not a reported result and is also excluded.

Figure 7 reads the locked counts in `../../../staged_ablation_annotated_20261001_093433/JUDGE_CODEX_DECODED_ANALYSIS.md`. All eight figures are generated by the same script.

Generate the physician-derived figures with:

```bash
python3 results/extraction_comparison/clinician_ratings/analyze_clinician_ratings.py
python3 results/extraction_comparison/clinician_ratings/plot_manuscript_figures.py
```

Files:

- `figure1_development_pathway_rough.svg`: four-panel data-isolation, breast development, PDAC adaptation, and holdout-evaluation schematic.
- `figure2_evaluator_distribution_rough.svg`: raw outcome composition and directional harness share for all eight physician-by-cancer analyses.
- `figure3_interrater_matrix_rough.svg`: paired exact agreement and Cohen's kappa for all four physicians, shown separately for breast cancer and PDAC.
- `figure4_core_fields_rough.svg`: diverging preference profile across seven core clinical categories.
- `figure5_note_margins_rough.svg`: ranked note-level harness-minus-baseline margins, pooled across four physicians within cancer type.
- `figure6_adjusted_effects_rough.svg`: single-panel overall and cancer-specific GEE forest plot on the probability scale, with standardized harness-preference probabilities, 95% confidence intervals, and differences from 50%. Odds ratios remain in the manuscript table and text.
- `figure7_staged_ablation_rough.svg`: A-D stage strip and adjacent-stage ablation results overall and by cancer.
- `figure7_human_model_complementarity_rough.svg`: results-informed three-lane clinical handoff concept, embedded as Figure 8.

The `rough` suffix is retained for backward-compatible HTML paths. The content is regenerated from source data and the locked ablation summary whenever physician exports or analysis specifications change. Across all figures, blue identifies the harness, orange the baseline, gray ties or neutral elements, green physicians, and purple LLM review.
